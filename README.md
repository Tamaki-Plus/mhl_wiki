
# 🔨 构建文档

> [!NOTE]
> 请先安装 Node.js 和 pnpm

1. 将此仓库克隆至本地
   `git clone https://github.com/Tamaki-Plus/mhl_wiki.git`
   更快的克隆 (推荐)
   `git clone --single-branch --depth 1 -b mainhttps://github.com/Tamaki-Plus/mhl_wiki.git`
2. 移动至仓库根目录
   `cd NitWikit`
3. 安装依赖
   `pnpm install`
4. 构建文档
   `pnpm build`
5. 本地预览
   `pnpm dev`
