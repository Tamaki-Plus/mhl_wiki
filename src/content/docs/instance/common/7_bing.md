## 副本机制

副本一共由三个阶段构成，全部击破即可通关



| 怪物名称 | 血量 | 掉落物 | 备注 |
|----------|------|--------|------|
| 冰晶爬行者 | 100/300 | 冰晶 | 伤害很高 |
| 霜鳞鱼人 | 600 | 海魔鳞片 | |
| 深海祭祀 | 240 | 海魔鳞片 | |
| 破冰 | 200 | | 高移速虫虫 |
| 冰屑 | 220 | | 高移速僵尸 |

- 本副本拥有寒冷值机制，每隔一段时间增加一层，达到十层后获得大量debuff


### 第一阶段

- 场地召唤怪物，全部击杀即可，共三轮
- 霜鳞鱼人\*8、深海祭祀\*1、冰晶爬行者\*1

### 第二阶段
- 场地中间召唤boss  **<高天之水>鼋一**
- boss拥有800点血量，高额的护甲和抗性IV
- 共三个技能：寒冰箭 结缘 冲锋砸地

### 第三阶段

- 玩家被传送至篝火处，需阻挡怪物的进攻，最多漏十只怪

| 波次 | 怪物数量 |
|------|----------|
| 第一波 | 霜鳞鱼人\*5、破冰\*3 |
| 第二波 | 霜鳞鱼人\*5、冰屑\*2、破冰\*3 |
| 第三波 | 霜鳞鱼人\*2、冰屑\*4 |
| 第四波 | 霜鳞鱼人\*3、深海祭祀\*4、冰晶爬行者\*1 |
| 第五波 | 寒冰巨像、冰屑\*1、破冰\*2 |
| 第六波 | 霜鳞鱼人\*6、冰屑\*3、破冰\*2、冰晶爬行者\*1 |

- 在第五波时场地后方出现boss **寒冰巨像** ，拥有5000点生命值及高额护甲

#### 克拉肯每隔一段时间释放buff

| Buff 名称 | 效果 |
|-----------|------|
| 迅捷 | 全场护卫移速+40% |
